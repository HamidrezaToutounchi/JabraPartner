# Jabra Partner Türkiye - Resmi B2B Distribütör & Yetkili Satış Portalı

Jabra'nın Türkiye'deki tüm kurumsal portföyünü (Ofis Kulaklıkları, Çağrı Merkezi, Saha/PTT, Konferans Hoparlörleri, Video Sistemleri ve Bulut Yazılımları) kapsayan kurumsal B2B proje ve satış platformu.

## 🚀 Özellikler

- **Tüm Kurumsal Portföy:** Evolve3, Evolve2, Engage, Biz, Perform, PanaCast, Speak2 ve Jabra+ Cloud yazılımları (31 kurumsal model).
- **Mega Menü & Cihaz Sihirbazı:** 6 ana ürün ailesine hızlı erişim ve ihtiyaç odaklı cihaz bulucu.
- **B2B Proje & Teklif Masası:** Deal registration koruması, adetli kurumsal iskonto ve demo cihaz başvuru formu.
- **4 Ürüne Kadar Karşılaştırma:** Farklı serilerin teknik özelliklerini matris tabloda inceleme.
- **Resmi Jabra GN Logosu & B2B Header:** Kurumsal koyu bilgi bandı ve temiz aydınlık tasarım dili.

## 🛠️ Kurulum ve Çalıştırma

```bash
# Bağımlılıkları yükleyin
npm install

# Geliştirme sunucusunu başlatın (Port 3003)
npm run dev

# Üretim derlemesi oluşturun
npm run build
npm run start
```
